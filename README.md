# Audio-Encoding_ulaw
### Audio Encoding ulaw High Qualitiy

Standardanwendung

µ-law (auch u-law oder PCMU) ist ein Kompandierungsverfahren im Sprachcodec ITU-T G.711 für die digitale Telefonie und VoIP. Es komprimiert lineare 14-Bit-PCM-Abtastwerte logarithmisch auf 8 Bit pro Sample bei einer Abtastrate von 8 kHz. µ-law verwendet den Container .au.

Anwendung für High Quality Audio

Man kann bei ulaw auch höhre Abtastraten encodieren. Wie bei CD Qualität kann man eine Abtastrate von 44.1 khz verwenden. Damit bleiben die Höhen erhalten bei Musikstücken. Es werden dabei Abtastwerte von 8 bit logarithmisch verwendet. Das bedeutet das im vergleich zum Standard CD PCM 16bit, 44.1khz eine Halbierung der Dateigrosse. CD Bitrate 1,411kbps, ulaw 705kbps.

Erfahrung Hörerlebis.

Beim normalen hören sind kaum negative Effekte feststellbar gewesen. Der Hörgenuss ist praktisch nicht eingeschränkt. ABX Test haben praktisch keine Unterscheitbarkeit gezeigt.
