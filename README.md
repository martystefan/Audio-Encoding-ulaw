# Audio-Encoding_ulaw
Audio Encoding ulaw High Qualitiy

Standardanwendung
µ-law (auch u-law oder PCMU) ist ein Kompandierungsverfahren im Sprachcodec ITU-T G.711 für die digitale Telefonie und VoIP. Es komprimiert lineare 14-Bit-PCM-Abtastwerte logarithmisch auf 8 Bit pro Sample bei einer Abtastrate von 8 kHz.
µ-law verwendet den Container .au.
